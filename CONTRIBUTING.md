# Contributing to One Ummah

Thank you for your interest in contributing to One Ummah!

## Getting Started

1. Fork the repository
2. Clone your fork: `git clone https://github.com/YOUR_USERNAME/one-ummah.git`
3. Create a branch: `git checkout -b feature/your-feature-name`
4. Make your changes
5. Commit: `git commit -m "Add your feature"`
6. Push: `git push origin feature/your-feature-name`
7. Open a Pull Request

## Development Setup

See `QUICKSTART.md` for detailed setup instructions.

## Code Style

- Frontend: TypeScript + React with ESLint
- Backend: Python with type hints
- Follow existing code patterns

## Testing

- Frontend: `npm run typecheck`
- Backend: `pytest` (in backend directory)

## Pull Request Process

1. Update documentation if needed
2. Ensure all tests pass
3. Request review from maintainers
4. Address feedback

## Questions?

Open an issue or contact the maintainers.
